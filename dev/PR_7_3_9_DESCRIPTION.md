DDESONN 7.3.9: Clarify R examples and improve code spacing

The workbench's dense R snippets and “Load and predict with a saved bundle” label left readers unsure what to run or what files they needed. Version 7.3.9 uses blank lines between logical blocks, explanatory section comments, comfortable line spacing and wrapping in help, code panels and the full-script viewer. Help remains specific to each title.

The saved-model option is now “R example: load a saved model and predict new rows.” Both its introduction and downloadable code explain the original intention: this began as a standalone script before the package API, to reload a saved model with its original settings and use it again. The example expresses that workflow through the current API. They also explain that a bundle is the .rds file from Save model, containing the trained model and preprocessing settings. Numbered steps cover replacing input paths, reading new predictor rows, reusing saved scaling and predicting without retraining. Classification outputs class probabilities; regression outputs numeric predictions. Saving a bundle copy and exporting the API model are separate optional steps. The example now prints its predictions.

Validation: installed-app desktop/mobile browser checks cover explanations, blank lines, line spacing, keyboard help and exact display/download parity. Focused workbench/dashboard tests and generated-recipe execution results are recorded in dev/readable-code-7.3.9-validation.md. Training and warm-start recipes preserve their executable code; completed saved recipes remain unchanged. The full numerical suite, vignette build and package check are not rerun for this presentation/documentation update. No merge, publication or release-tag changes are included.
