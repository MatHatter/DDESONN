Compare DDESONN and Keras under original training settings with predictor overlap removed

The archived Keras experiment allowed identical predictor vectors across training, validation and test partitions. This comparison retains its training settings while grouping identical predictors into one partition, and runs 100 fresh seeds for each of four conditions: Keras mean, DDESONN FALSE/sum, DDESONN TRUE/mean, and Keras sum. The DDESONN results use an opt-in native float32 matched-protocol adapter; the default trainer is unchanged.

All 400 fits are complete. Mean held-out accuracy is 91.36% versus 87.48% for sum, and 90.39% versus 87.62% for mean. Independent audits find zero exact predictor overlap in both raw data and actual float32 inputs. All conditions use the same frozen split, train-only scaler, shared initial tensors, batch size 16, 360 epochs and final checkpoint. Framework-native stochastic streams differ.

The report includes ten disjoint seed blocks, cumulative paired differences and pointwise confidence intervals, and precision plots with a clearly labeled synthetic comparison. All ten block averages favor the adapter in both comparisons. Retaining 100 seeds is a retrospective resource/precision decision: the final seed-based interval half-widths are 0.77 and 0.85 percentage points. These are conditional on one split, not confidence intervals for generalization across datasets or a prespecified sequential stopping test. Historical overlapping results are marked superseded for this comparison.

Four runnable entry points and a contribution guide allow optional additional seeds using the frozen protocol. Preparation generates additional shared initial tensors; portable native compilation and independent numerical checks support other Linux workspaces. Export validates complete four-condition bundles and preserves the published 100-seed cohort. Contributors supply raw metrics, environment records and provenance in separately identified PRs; pooled analyses must reject duplicates and disclose environment differences.

Validation: the original 400-fit strict completion checks, raw/float32 overlap audits, 146 TensorFlow/native numerical comparisons, independent decile arithmetic checks, and rendered figure review passed. Community-extension smoke-check results are recorded in COMMUNITY_VALIDATION.md. No new full training fits were launched for the extension workflow.
