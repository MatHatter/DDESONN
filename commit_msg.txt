### Observations
• Directional accuracy improved — fewer sign mismatches between actual and predicted.
• Mean absolute error_pct100 reduced by roughly **50 %** (Phase 2 ≈ 0.95 → Phase 3 ≈ 0.46).
• Phase 3 captures cross-market effects (SPY, XLP, VIX), stabilizing predictions.
• Predictive magnitudes better aligned with actual returns, indicating improved calibration.

### Interpretation
Phase 2 underfit due to narrow input space, often predicting wrong direction.
Phase 3 introduces contextual awareness, allowing the model to track regime shifts
and produce smoother, less volatile predictions.

No functional code changes were introduced; this commit is strictly a results documentation update.
